# Subvio Music — نسخهٔ اولیه اندروید

پخش‌کنندهٔ سبک موسیقی با رابط فارسی و تم تیره.

## قابلیت‌های این نسخه
- انتخاب فایل‌های صوتی محلی از گوشی (MP3 و فایل‌های صوتی پشتیبانی‌شده توسط Android)
- جست‌وجو در فهرست اضافه‌شده
- انتخاب آهنگ، پخش/مکث، آهنگ قبلی و بعدی
- حذف آهنگ از فهرست برنامه
- پیکربندی پخش در پس‌زمینه و کنترل صفحهٔ قفل از طریق `expo-audio`

## پیش‌نیاز
- کامپیوتر Windows / macOS / Linux
- Node.js نسخهٔ LTS
- اتصال اینترنت برای دریافت وابستگی‌ها و ساخت اولیه

## اجرای آزمایشی
1. پوشهٔ `Subvio-Music` را از فایل ZIP خارج کن.
2. ترمینال را در همین پوشه باز کن.
3. اجرا کن:
   ```bash
   npm install
   npx expo start
   ```
4. برای اجرای مستقیم روی گوشی متصل به کامپیوتر، Android Studio و Android SDK نصب کن و اجرا کن:
   ```bash
   npx expo run:android
   ```

## ساخت فایل APK قابل نصب
برای ساخت APK مستقل با EAS Build:
1. حساب Expo بساز و وارد شو:
   ```bash
   npx eas-cli login
   ```
2. EAS CLI را نصب کن:
   ```bash
   npm install -g eas-cli
   ```
3. فایل `eas.json` ایجاد کن (نمونه در ادامه) و سپس:
   ```bash
   eas build:configure
   eas build -p android --profile preview
   ```
4. پس از اتمام ساخت، لینک APK را از خروجی EAS باز کن و APK را روی گوشی نصب کن.

## نمونهٔ `eas.json`
```json
{
  "build": {
    "preview": {
      "distribution": "internal",
      "android": {
        "buildType": "apk"
      }
    },
    "production": {}
  }
}
```

## نکته‌های مهم
- این بسته **کد منبع پروژه** است، نه فایل APK از پیش ساخته‌شده. ساخت APK اندروید نیازمند فرایند Build است.
- نسخهٔ اولیه فهرست آهنگ‌های انتخاب‌شده را پس از بستن برنامه به‌صورت دائمی ذخیره نمی‌کند؛ برای نسخهٔ بعدی می‌توان ذخیره‌سازی محلی و اسکن خودکار کتابخانه را اضافه کرد.
- انتخاب فایل با Document Picker انجام می‌شود و دسترسی به پوشه‌های دیگر گوشی بدون انتخاب کاربر انجام نمی‌شود.
- قابلیت‌های پس‌زمینه و صفحهٔ قفل به پشتیبانی نسخهٔ Expo و دستگاه وابسته‌اند؛ حتماً روی گوشی واقعی آزمایش شود.
